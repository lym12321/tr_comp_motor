### components::motor

- `motor/dji.h`: 实现对大疆 GM6020、M3508、M2006 的基础驱动
- `motor/dm.h`: 实现对达妙电机的基础驱动
- `motor/gyj.h`: 实现对葛老板直流电机电调的基础驱动

各电机继续通过 `init()` 完成初始化，DJI/GYJ 自动周期发送，无需额外启动入口。
DJI/GYJ 的 `disable()` 清除输出并关闭本地输出门控，不清除测量历史；禁用期间收到的反馈仍会更新。
显式 `clear()` 保留原有重置输出和反馈历史的行为，DJI 累计圈数也会重置。
`enabled` 是本地输出门控，不是远端已停止的确认；反馈是否继续到达取决于设备及协议配置。
GYJ 的 `init()`、`enable()`、`disable()` 和 `set_mode()` 返回模式帧的 CAN 提交状态。首次启用提交成功后才开放本地输出。禁用会立即清零本地输出，提交失败时可重试 `disable()`。
GYJ 的 `init()` 每台电机只调用一次。若首次模式帧提交失败，接收回调已经注册，直接重试 `enable()`。
DM 的 `reset()`、`enable()` 和 `disable()` 每次提交一帧 CAN 命令并返回 BSP 状态，应用按需重试。`state()` 保留最近一帧实际反馈。MIT 模式以量化到协议后的增益校验，非零 Kp 配零 Kd 时提交停用命令。
DJI 仅接受 0 至 8191 的编码器读数。越界帧整帧丢弃，`state().timestamp` 保留上一有效反馈的时间。
